Connect an existing Casambi network

Choose a saved network or a nearby device. One-time online setup downloads authorized network keys and light profiles. After setup, lighting control stays local.

Prepare your light before adding it
  1. Power the light and add it to an Evolution network in the official Casambi app. Check that you can control it there. Keep an existing working network; no reset or unpairing is needed.
  2. For this P0 online setup, an administrator must open More → Network setup → Sharing settings and use Password protected sharing. Add a User password for lighting control and save/synchronize the changes while online. Administrator-only lookup is not supported by this wizard.
  3. Keep the light powered within Bluetooth range of Homey. Close the Casambi app during pairing to avoid competing connections, then scan here.

Enter the network User password below, not an email login, account password or Bluetooth PIN. You do not need to make the network Open. An authorized offline export is an alternative to online setup.

Required only for a new network. Sent to Casambi over HTTPS once; not saved. Local-control keys remain in private storage on Homey. A saved network needs no password.
